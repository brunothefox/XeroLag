Check the file
before you open it.

This build is unsigned. Its SHA-256 checksum lets you compare the download with the release file.

In PowerShell, from the folder containing the installer:

Get-FileHash .\XeroLag-Setup-0.3.1-x64.exe -Algorithm SHA256

Compare the result with the .sha256 release asset. The values should match exactly.

Before you install.

A few things worth knowing.

Why does Windows show an unknown publisher?

The current build does not have a code-signing certificate. Verify that you downloaded it from this repository and compare its checksum. If you are unsure about the file, do not run it.

Does setup change Windows settings?

Setup installs the app and your chosen shortcut. Optimizations are separate actions inside XeroLag. Review each change and create your recovery snapshot first.

Will an update keep my backups?

Yes. Installing over an existing version retains XeroLag recovery data. Keep those backup files intact so saved original settings remain available.

Does it need an internet connection?

The installer includes the full app and works offline. Some app features, including online game artwork and application updates, need a connection.

Does uninstalling undo my tweaks?

No. Restore saved changes using Recovery inside XeroLag before uninstalling if you want to return to your original settings. Uninstalling keeps recovery backups.
